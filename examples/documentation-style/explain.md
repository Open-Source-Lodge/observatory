# Write documentation in ASD-STE100

## Why

Many readers do not have English as their first language. Simplified
Technical English gives each word one meaning and keeps sentences short.
Thus a reader understands a document on the first read, and a translation
stays correct.

## What the rule covers

- `README.md` and each other document in the repository.
- Comments in the source code.
- Help text and error messages that a user reads.

## What the rule does not cover

- Code, including identifiers.
- The output of a program, quoted in a code block.
- Technical names, such as `rule`, `commit` and `token`.

## The primary rules

- Use a maximum of 20 words in an instruction, and 25 in a description.
- Write one instruction in one sentence.
- Use the active voice and the simple present, past or future tense.
- Use the same word for the same thing in all the documents.
- Use the articles `the`, `a` and `an` where possible.
- Write a maximum of six sentences in a paragraph, about one topic.

This repository uses this rule on itself. See `.observatory/OBS-001`.
